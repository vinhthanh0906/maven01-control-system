# Maven-01 Rover Monitoring System

A Python + Qt based monitoring and control system for the **Maven-01 Rover**.  
This application provides a graphical interface to connect, monitor telemetry, and control rover operations in real time.


## 1. Clone Repository

```bash
git clone https://github.com/yourusername/maven-01-control-system.git
cd maven-01-control-system

```bash
conda create -n robotics python=3.12
```

## 2. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3. Start the Application

```bash
python main.py
```
---

## Connecting to Maven-01 Rover

- Connect to wifi 'RoverAP' with password

## Telemetry Information

The monitoring system can display:
- Battery voltage
- Sensor data
- Gyro
- Temperature, Humidity, Pressure
- Camera stream

---

## Run the App

```bash
python main.py --debug
```
